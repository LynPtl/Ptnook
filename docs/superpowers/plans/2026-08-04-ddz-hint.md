# 斗地主「提示」按钮 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 轮到出牌的玩家点「提示」按钮，服务端用 enumerateLegalPlays 选出最小合法一手回传，前端高亮为当前选中，玩家可直接出牌。

**Architecture:** 提示在服务端算（复用引擎）。新增纯函数 `pickHint(plays)` 从候选中选"最小一手"。DO 加 `ddz_hint` 消息分支：校验轮次→枚举合法出牌→pickHint→回 `ddz_hint {cards}` 或 `ddz_error`。前端出牌区加「提示」按钮，收到 cards 后按令牌匹配手牌索引写入 ddz.selected 并高亮。

**Tech Stack:** JavaScript、Cloudflare Workers、Durable Objects、Vitest + vitest-pool-workers。零依赖。

## Global Constraints

- 只改 `src/ddz.js`（加 pickHint + 单测）与 `src/worker.js`（DO 分支 + 前端）。现有 54 测试须全绿。
- 消息协议新增：C→S `{type:"ddz_hint"}`（无参）；S→C `{type:"ddz_hint", cards:[令牌...]}`（仅请求者）；要不起复用 `{type:"ddz_error", text:"没有能压过的牌，只能过"}`。
- `pickHint(plays)`：`plays` 为候选二维数组（每项是令牌数组，来自 enumerateLegalPlays）。返回"最小一手"：先按**牌数（长度）升序**，长度相同按 `identifyPlay(play).rank` 升序，取第一手。`plays` 为空 → 返回 `null`。纯函数，放 src/ddz.js，consumes 已有 `identifyPlay`。
- DO `ddz_hint`：phase 必须 `playing`；nick 必须 === `g.current`（否则 ddzErr「还没轮到你」）；`last = g.lastPlay ? g.lastPlay.cards : null`；`enumerateLegalPlays(g.hands[nick], last)` 为空 → ddzErr「没有能压过的牌，只能过」；否则 `pickHint` 后回 `{type:"ddz_hint", cards}` 仅发请求者。
- 前端：出牌阶段且轮到自己时「提示」按钮与「出牌」「过」并列；点击 `ddzSend("ddz_hint")`；收到 `ddz_hint` → 按令牌依次匹配 ddz.hand 索引写入 ddz.selected（重复点数按出现次序匹配）→ renderHand()。所有牌面 textContent 不变。
- commit message 不得含 `Co-authored-by: TRAE CLI` 或任何 TRAE 署名（自动 `Change-Id:` 允许）。

```js
export function pickHint(plays) {
  if (!plays || plays.length === 0) return null;
  let best = null;
  let bestLen = Infinity;
  let bestRank = Infinity;
  for (const play of plays) {
    const info = identifyPlay(play);
    const rank = info ? info.rank : Infinity;
    if (play.length < bestLen || (play.length === bestLen && rank < bestRank)) {
      best = play;
      bestLen = play.length;
      bestRank = rank;
    }
  }
  return best;
}
```

```js
  function applyHint(cards) {
    ddz.selected = {};
    // 按令牌逐张匹配 ddz.hand 中尚未选中的同点数位置（处理重复点数）
    cards.forEach(function (c) {
      for (var i = 0; i < ddz.hand.length; i++) {
        if (ddz.hand[i] === c && !ddz.selected[i]) { ddz.selected[i] = true; break; }
      }
    });
    renderHand();
  }
```
