# 斗地主体验修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复本地测试反馈的 7 项斗地主体验/逻辑问题，全部集中在 src/worker.js（DO 状态机 + 内联前端），引擎 src/ddz.js 不动。

**Architecture:** 服务端改动集中在广播文案与游戏状态字段（settle/pass/play 广播、startBidding 轮换首叫、disband 发榜）；前端改动集中在 renderDdz 的手牌条清空时机。分 3 个任务：DO 服务端一批（1/3/4/5/7）、前端手牌条清空（2/6）、跑通全流程回归。

**Tech Stack:** JavaScript、Cloudflare Workers、Durable Objects、Vitest + vitest-pool-workers。零依赖。

## Global Constraints

- 只改 `src/worker.js`；`src/ddz.js` 引擎不改。现有 51 测试须全绿。
- 座位顺序 = `g.players`（长度 3）。累计分 `g.scores[nick]`。
- 牌面文字化：小王→`小王`、大王→`大王`、其余→点数令牌（服务端广播可直接用 `cards.join(" ")`，令牌本身即 3..10/J/Q/K/A/2/x/X；为可读，大小王在服务端广播用 `cardText` 辅助转成中文）。
- 剩余张数广播按座位顺序列出三家：格式 `剩余 <nick><n> <nick><n> <nick><n>`。
- 再来一局首叫轮换：新增 `g.firstBidIndex`（座位索引）。首次开局设为 0；每次「再来一局」`firstBidIndex = (firstBidIndex + 1) % 3`，bidOrder 从该索引起、bidTurn = bidOrder[0]。
- 散桌发榜：`clearGame()` **之前**，若 `g.scores` 有任一非零值，按分数从高到低广播 `本桌战绩 — <nick> <+/-分>，…。牌桌已解散。`；全 0/空则不发榜。中途退出时当前局作废（本就不结算），历史局累计分计入榜。
- commit message 不得含 `Co-authored-by: TRAE CLI` 或任何 TRAE 署名（自动 `Change-Id:` 允许）。

  cardText(c) { return c === "x" ? "小王" : c === "X" ? "大王" : c; }
  remainStr(g) {
    return "剩余 " + g.players.map((p) => `${p}${(g.hands[p] || []).length}`).join(" ");
  }
  rankBoard(g) {
    const entries = g.players.map((p) => [p, g.scores[p] || 0]);
    if (!entries.some(([, v]) => v !== 0)) return null;
    entries.sort((x, y) => y[1] - x[1]);
    return entries.map(([p, v]) => `${p} ${v >= 0 ? "+" : ""}${v}`).join("，");
  }

**第 3 项（结算展示剩余手牌）**：把 `settle` 的广播改为：
```js
  async settle(g, winnerNick) {
    g.phase = "settled";
    g.winner = winnerNick;
    const landlordWon = winnerNick === g.landlord;
    const li = g.players.indexOf(g.landlord);
    const delta = computeScores(li, landlordWon, g.base, g.bombCount, g.hasRocket);
    for (let i = 0; i < 3; i++) {
      const p = g.players[i];
      g.scores[p] = (g.scores[p] || 0) + delta[i];
    }
    await this.putGame(g);
    const hands = g.players.map((p) => {
      const h = sortCards(g.hands[p] || []).map((c) => this.cardText(c)).join(" ");
      return `${p}：${h || "无"}`;
    }).join("；");
    const summary = g.players.map((p, i) => `${p} ${delta[i] >= 0 ? "+" : ""}${delta[i]}（累计 ${g.scores[p]}）`).join("，");
    this.broadcast(systemMsg(`本局结束，${landlordWon ? "地主" : "农民"}胜。剩余手牌 — ${hands}。${summary}`, Date.now()));
    await this.sendDdzState(g);
  }
```
